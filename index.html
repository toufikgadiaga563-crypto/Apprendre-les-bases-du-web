1. HTML : structurer le contenu

HTML signifie « langage de balisage hypertexte ». Il décrit le rôle du contenu avec des balises : titres, paragraphes, listes, liens et images. Ce n'est pas un langage de programmation ; c'est le squelette de la page. 

<!DOCTYPE html>
<html lang="fr">
  <head>
    <meta charset="UTF-8">
    <title>Ma page</title>
  </head>
  <body>
    <h1>Bonjour !</h1>
    <p>Voici ma première page.</p>
  </body>
</html>

<head> : les informations

Cette partie contient les informations de la page, comme son titre et l'encodage des caractères.

<body> : le contenu

Tout ce qui doit apparaître dans la page — titres, textes, images et liens — va dans cette partie.

Exemple HTML : la page d'Ulrich

Voici le code complet d'une petite page de présentation. Le navigateur lit ce code de haut en bas et construit la page visible à droite. 

<!DOCTYPE html>
<html lang="fr">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>La page d'Ulrich</title>
  </head>
  <body>
    <article class="profil-demo">
      <h3>Bonjour, je m'appelle Ulrich !</h3>
      <p>J'apprends les bases du développement web.</p>
      <h4>Ce que j'apprends</h4>
      <ul>
        <li>HTML pour le contenu</li>
        <li>CSS pour le style</li>
        <li>JavaScript pour les interactions</li>
      </ul>
      <span class="badge">Débutant en développement web</span>
      <p>
        <a href="https://developer.mozilla.org/fr/docs/Web/HTML">
          Découvrir la documentation HTML
        </a>
      </p>
      <button type="button">Dire bonjour à Ulrich</button>
    </article>
  </body>
</html>

Le code expliqué étape par étape

1

<!DOCTYPE html> : annoncer HTML moderne

Cette déclaration dit au navigateur d'interpréter le document comme du HTML moderne. Elle se place tout en haut et n'a pas de balise fermante.

2

<html lang="fr"> : ouvrir la page

<html> contient toute la page. L'attribut lang="fr" précise que le contenu est en français. La balise se ferme tout à la fin avec </html>.

3

<head> : préparer les informations

Le contenu de <head> donne des informations au navigateur ; il ne s'affiche généralement pas dans la page elle-même. <meta charset="UTF-8"> permet d'afficher correctement les accents. La balise <meta name="viewport" content="width=device-width, initial-scale=1.0"> aide la page à s'adapter à la largeur des téléphones et tablettes.

4

<title> : nommer l'onglet

<title>La page d'Ulrich</title> définit le texte affiché dans l'onglet du navigateur. Il se trouve dans <head>.

5

<body> : écrire ce qui sera visible

Tout le contenu principal va entre <body> et </body>. Dans l'exemple, le titre, le texte, la liste et le lien apparaissent dans cette partie.

6

<h1>, <p> et <h2> : structurer le texte

<h1> est le titre principal de la page. <p> crée un paragraphe. <h2> est un sous-titre qui annonce une nouvelle partie.

7

<ul> et <li> : créer une liste

<ul> ouvre une liste à puces. Chaque <li> représente un élément. On ferme chaque élément, puis la liste, avant de continuer la page.

8

<a href="..."> : ajouter un lien

<a> crée un lien et l'attribut href contient son adresse. Le texte entre la balise ouvrante et </a> est le texte cliquable.

9

Fermer les balises dans le bon ordre

La plupart des éléments ont une balise ouvrante, par exemple <p>, et une balise fermante avec une barre oblique, </p>. Les balises imbriquées se ferment dans l'ordre inverse de leur ouverture.

HTML : les balises essentielles

Une balise indique au navigateur le rôle du contenu. Par exemple, <p> signifie « paragraphe ».

<h1> à <h6>

Des titres, du plus important au moins important. Une page a généralement un seul titre principal <h1>.

<p>

Un paragraphe de texte. On écrit le contenu entre <p> et </p>.

<ul> et <li>

<ul> crée une liste à puces ; chaque élément de la liste est placé dans <li>.

<a>

Crée un lien. L'attribut href indique son adresse, par exemple href="https://example.com".

<img>

Affiche une image. Ses attributs src et alt indiquent son fichier et une description textuelle.

Les attributs

Ils ajoutent des informations à une balise ouvrante, comme lang="fr" ou href="...".

Petit exercice pour Ulrich : dans index.html, remplace le texte d'un paragraphe, ajoute un titre <h2> et une liste <ul> avec trois choses que tu aimerais créer.

2. CSS : donner du style à la page

CSS signifie « feuilles de style en cascade ». Il décrit l'apparence des éléments HTML : couleurs, tailles, espaces, bordures et disposition. Nous reprenons la fiche d'Ulrich et ajoutons le badge et le bouton que nous utiliserons ensuite en JavaScript. 

.profil-demo {
  max-width: 420px;
  margin: 0 auto;
  padding: 24px;
  background-color: #eff6ff;
  border: 1px solid #bfdbfe;
  border-radius: 16px;
  font-family: Arial, sans-serif;
}

.profil-demo h3 {
  margin-top: 0;
  color: #1d4ed8;
}

.profil-demo .badge {
  display: inline-block;
  padding: 6px 10px;
  border-radius: 999px;
  background-color: #dbeafe;
  color: #1e40af;
}

.profil-demo .badge:hover {
  background-color: #bfdbfe;
}

.profil-demo button {
  margin-top: 16px;
  background: #2563eb;
  color: white;
  border: 0;
  border-radius: 10px;
  padding: 12px 16px;
  cursor: pointer;
}

Le CSS expliqué étape par étape

1

Écrire une règle CSS

Une règle commence par un sélecteur, suivi d'accolades. Les déclarations entre { et } indiquent les styles à appliquer.

2

.profil-demo : choisir l'élément à styliser

Le point devant profil-demo sélectionne tout élément HTML qui possède class="profil-demo". On appelle cela un sélecteur de classe.

3

Écrire une déclaration : propriété et valeur

Dans color: #1d4ed8;, color est la propriété et #1d4ed8 sa valeur. Chaque déclaration se termine par un point-virgule.

4

Régler la taille et les espaces

max-width limite la largeur, padding ajoute de l'espace à l'intérieur et margin ajoute de l'espace à l'extérieur. margin: 0 auto; centre la fiche horizontalement.

5

Ajouter couleurs et bordures

background-color définit la couleur de fond, color celle du texte, border ajoute une bordure et border-radius arrondit les coins.

6

.profil-demo h3 : viser un élément à l'intérieur

Un espace entre les sélecteurs signifie « l'élément à l'intérieur de ». Cette règle ne vise donc que le titre <h3> qui se trouve dans la fiche d'Ulrich.

7

.badge:hover : réagir au passage de la souris

:hover est un état spécial : la règle s'applique quand le pointeur passe sur le badge. Ici, sa couleur de fond change.

8

Relier le CSS à la page HTML

Pour commencer, tu peux écrire le CSS dans une balise <style> placée dans le <head>. Dans un projet plus grand, on le met souvent dans un fichier séparé, puis on le relie avec <link rel="stylesheet" href="style.css">.

Petit exercice pour Ulrich : dans la règle .profil-demo h3, change la valeur de color, puis modifie le border-radius de la fiche et observe le résultat.

3. JavaScript : rendre la page interactive

JavaScript ajoute des actions à la page. Nous reprenons la même fiche et son bouton : au clic, le texte du paragraphe change pour afficher un message destiné à Ulrich. 

const bouton = document.getElementById("bouton-ulrich");
const message = document.getElementById("message-ulrich");

bouton.addEventListener("click", function () {
  message.textContent = "Bonjour Ulrich ! Le bouton fonctionne.";
});

Le JavaScript expliqué étape par étape

1

Préparer les éléments HTML à relier

Dans le HTML, écris le paragraphe comme <p id="message-ulrich">...</p> et le bouton comme <button id="bouton-ulrich">Dire bonjour à Ulrich</button>. Ces identifiants servent de noms uniques pour que JavaScript retrouve les bons éléments.

2

document : accéder à la page

document représente la page HTML ouverte dans le navigateur. JavaScript peut s'en servir pour retrouver et modifier les éléments de la page.

3

getElementById(...) : retrouver un élément

document.getElementById("bouton-ulrich") cherche l'élément HTML qui a id="bouton-ulrich". L'identifiant doit correspondre exactement à celui écrit dans le HTML.

4

const : garder une référence

const bouton = ... place l'élément retrouvé dans une variable appelée bouton. La deuxième ligne fait la même chose pour le paragraphe du message.

5

addEventListener("click", ...) : attendre un clic

Cette méthode demande au navigateur d'exécuter une action lorsque l'utilisateur clique sur le bouton. "click" est le nom de l'événement surveillé.

6

La fonction : décrire l'action à faire

function () { ... } contient les instructions qui seront exécutées après le clic. Le code à l'intérieur des accolades correspond à l'action.

7

textContent : changer le texte

message.textContent = "..." remplace le texte du paragraphe par le nouveau message. Le signe = affecte la valeur située à droite à l'élément situé à gauche.

8

Relier JavaScript à HTML

Le bouton et le paragraphe doivent exister dans le HTML avec les identifiants bouton-ulrich et message-ulrich. Le code JavaScript se place généralement dans une balise <script> à la fin du <body>, pour que les éléments soient déjà chargés.

Petit exercice pour Ulrich : change le texte dans textContent pour écrire ton propre message. Ensuite, modifie le paragraphe dans HTML et vérifie que le bouton remplace bien son texte quand tu cliques dessus.
